AuthentiScan Pro Widget

Embed the widget on any article or product page to show, in a compact badge, the credibility verdict for that content. Isolated with Shadow DOM — your site's CSS won't interfere with the widget.

Live examples

How to use — declarative mode

Include the script once and add a container with data-* attributes:

<div class="authentiscan-widget"
     data-score="92"
     data-signals='[{"label":"Source","value":90},{"label":"Language","value":74},{"label":"Images","value":58}]'
     data-url="https://example.com/article"></div>

<script src="https://app.authentiscanapp.com/widget.js" async></script>

How to use — programmatic mode

Useful when you already have the analysis result and want to render it via JavaScript:

<div id="my-badge"></div>
<script src="https://app.authentiscanapp.com/widget.js"></script>
<script>
  AuthentiScan.render("#my-badge", {
    score: 12,                        // 0-100 (risk; higher = worse)
    // verdict: "Trustworthy",        // optional: overrides the automatic label
    signals: [
      { label: "Trustworthy source", value: 10 },
      { label: "Balanced tone",      value: 18 },
      { label: "Verified data",      value: 8 }
    ],
    url: "https://example.com/article" // link to the full analysis
  });
</script>

The verdict is derived from the score automatically: ≥ 66 = High Risk (red), 33–65 = Verify (yellow), < 33 = Trustworthy (green).
